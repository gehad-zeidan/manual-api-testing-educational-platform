## Project Overview

This repository showcases a complete **Manual API Testing** project for an Educational Platform.

The project focuses on the **Authentication** and **Course Management** modules and demonstrates the complete manual API testing workflow, including test planning, test case design, API validation, static API review, test execution, and defect reporting.

---

## Scope

### Authentication Module

- Sign Up
- Login
- Send Verification Code
- Validate Verification Code

### Course Management Module

- Create Course
- Get Course by ID
- Get All Courses
- Update Course
- Delete Course
