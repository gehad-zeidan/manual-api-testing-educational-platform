Educational Platform – Manual API Testing

## Project Overview

This repository contains the manual API testing documentation for the Mestar Educational Platform.

The project covers the Authentication and Course Management modules and includes the complete manual testing process from planning and test design to execution and defect reporting.

---

## Scope

### Authentication Module
- Sign Up
- Login
- Send Verification Code
- Validate Verification Code

### Course Management Module
- Create Course
- Get Course by ID
- Get All Courses
- Update Course
- Delete Course
